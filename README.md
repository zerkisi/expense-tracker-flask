# \# Personal Expense Tracker

# 

# \## Overview

# This is a multi-user web application built with Flask.

# 

# \## Features

# \- User authentication (register, login, logout)

# \- Multi-user system (each user sees only their own data)

# \- CRUD operations for expenses

# \- Category filtering

# \- Total expense calculation

# 

# \## Technologies

# \- Flask

# \- SQLite (raw SQL)

# \- HTML / CSS

# 

# \## How to Run

# ```bash

# pip install -r requirements.txt

# flask --app app init-db

# flask --app app run
